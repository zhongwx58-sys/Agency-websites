# 常用检测网站与用途

按出口、地区与 ASN、DNS、WebRTC 和 IPv6 介绍工具。

## 按问题挑选检测工具

想知道一次网页请求从哪里出来，使用当前 IP 检测；想了解地址归属，查看 ASN 和地区资料；想检查解析路径，使用 DNS 检测；想观察浏览器实时通信暴露的候选信息，使用 WebRTC 检测；想确认双栈连通，选择 IPv6 测试。这些问题需要不同证据，不能用一个分数替代全部项目。

## 从最小检测组合开始

IPinfo 的当前 IP 页面可作为出口与归属资料入口，BrowserLeaks 提供 IP、DNS 和 WebRTC 的独立页面，Test IPv6 可补充双栈连通检查。先运行与当前问题相关的一项，再按需要补充。外站可能包含商业内容，本教程仅提供明确用途的直达入口，不代表对其全部页面内容背书。

1. 记录当前规则模式和选中的策略。
2. 打开检测页并保存结果时间。
3. 回到客户端找到这次检测请求的连接记录。

## 先判断测试自身是否完成

页面空白、脚本未运行或某个测试目标不可达时，应记录为未完成，而不是推断没有泄漏或网络安全。不要为了得到满分立即修改所有网络设置。将检测站故障与代理故障分开，再通过另一个不同来源的检测交叉核对，同时保留实际目标网站的访问结果。

## 常见误区

把测试加载失败当成检测通过，或把风险评分当作可用性保证。

## 恢复与回退

恢复为测试前的客户端设置，改用另一检测入口并记录无法完成的项目。
