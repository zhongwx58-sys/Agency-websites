# 准备导入材料

整理订阅链接、节点参数或配置文件，记录系统和客户端版本。

## 确认材料的类型

订阅链接通常用于下载节点列表或完整配置；单节点分享链接通常只描述一个节点；配置文件还可能包含 DNS、策略组和规则。先查看来源说明支持哪一种客户端格式，不要仅凭文件名是 YAML 或 JSON 就判断兼容。

## 建立一张导入清单

在本地保存配置的来源、获取时间和适配客户端。版本记录应包含系统、客户端界面版本和内核版本；界面相同不代表内核相同。节点参数按提供方原样核对，端口必须是端口数字，协议类型不能靠端口猜。

1. 记录系统和芯片架构，选择匹配的安装包。
2. 确认订阅格式，或整理地址、端口、协议、认证和传输参数。
3. 保存一份旧配置，记录当前是否启用系统代理或 TUN。
4. 公开交流时遮挡订阅令牌、账号、密码和二维码。

## 导入前做一次静态核对

检查链接有没有多复制空格、换行或聊天软件的标点。配置文件应是文本配置，而不是下载失败得到的网页。分享截图只保留字段名和必要错误信息；别人拿到完整订阅地址可能获得同一组访问凭据。下一课只导入一份材料，便于定位问题。

## 常见误区

不要把私人订阅粘贴到不明在线转换或检测服务中。

## 恢复与回退

导入前尚未切换网络；材料不明确时保留原配置，回到来源核对格式。
