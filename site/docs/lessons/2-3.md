# 获取并导入订阅

围绕后续共同确认的服务制作控制台到客户端的操作图文。

## 找到适配格式的入口

在自己使用的服务控制台中寻找订阅或客户端配置入口，核对说明支持的客户端。不同入口可能返回不同格式。这里不放商家登录页或虚构控制台截图；下面提供通用操作检查表，真实服务的图文需结合你的账户界面补充。

## 完成一次可追踪导入

只在本机客户端输入私人订阅。将新配置命名为能辨认来源和用途的名称，不使用包含密码的名字。

1. 复制适配的订阅链接，确认没有额外空格或引号。
2. 打开客户端的订阅或配置管理，新增远程配置。
3. 粘贴链接并下载，查看是否报格式或认证错误。
4. 选中导入的配置，在节点列表确认资源出现，再选择一条测试。

## 遇到失败先判断返回的是什么

格式错误可能来自错误的客户端格式，也可能是订阅过期后返回了错误网页。下载失败则需检查获取订阅的网络路径和地址有效性。只保存脱敏错误信息，不把完整地址贴到公共讨论中。成功后核对规则与 DNS 是否随配置改变，再按第 1.5 课检查连接、出口和目标。

## 常见误区

直接修改远程下载文件可能在下一次更新时被覆盖。

## 恢复与回退

重新选中旧配置；不删除仍可用的旧订阅，待新配置验证通过再整理。
