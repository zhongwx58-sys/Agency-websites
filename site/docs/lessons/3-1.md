# 服务器选型与费用

比较地区、线路、带宽、流量、系统、IP 与续费成本。

## 先考虑你要维护什么

自建意味着除了客户端，还要管理服务器系统、代理服务、端口、凭据、更新和费用。服务器在远端运行，并不会自动提供一条可用代理。选择资源前，先确认自己能够登录控制台、使用 SSH，并愿意保留配置和故障记录。

## 拆开资源指标

地区是位置，线路是实际路径，端口带宽是链路能力之一，月流量是计费额度。它们不能用一个“高速”概括。系统架构决定安装包选择；IPv4、IPv6、共享地址或端口映射，也会影响接入方案。

1. 记录目标地区、操作系统与 CPU 架构。
2. 核对公网地址类型、入站限制和可开放端口。
3. 核对月流量、超额费用、周期、续费和自动扣费。
4. 查清控制台救援、快照、备份与删除资源的操作方式。

## 给第一套方案限制范围

先使用一台已有或已选定的服务器、一种内核、一种协议，避免同时引入面板、复杂链式和多地区。费用表应注明日期；本课没有实时采购报价或商家排名。若无法确认服务器到本地的连通情况，将其写为待验证项，不以配置参数替代网络测试。

服务器规格和地理位置不能证明特定网络时段的连接质量。
