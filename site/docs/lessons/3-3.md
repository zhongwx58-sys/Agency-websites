# 选择可复现的部署方案

先固定一条 Xray 或 sing-box 教学主线，核对官方安装来源。

## 本路线先以 Xray 为记录对象

第一版采用 Ubuntu 服务器与 Xray 的部署检查路线，便于统一文件、版本与诊断方法；这里不假装提供已经实测的整套服务器成品。具体协议、传输和认证仍须与自己的客户端及资源条件配套，选定后再进入安装步骤。

## 写清可复现所需信息

复现不只需要一段安装命令。还需要知道下载来源、文件版本、服务器系统、配置路径、启动方式以及客户端对应字段。来源页面提供多个平台包时，按服务器架构选择，不能按自己电脑的架构选择。

1. 从 Project X 官方安装文档进入发布页面。
2. 记录选定版本、压缩包名称及其校验信息。
3. 列出入站协议、监听端口、认证和传输所需参数。
4. 确认客户端支持这些参数，再准备服务端配置。

## 保持内核路线独立

Xray 与 sing-box 都可作为部署工具，但配置结构和字段并不互换。更换内核应作为一次明确的迁移，不是把两个教程的段落拼起来。来源不明的一键脚本会增加维护与复现难度；本课优先让你认识原始文件、服务和日志的对应关系。

## 常见误区

成功运行安装脚本不表示服务配置、端口和客户端均已正确。

## 恢复与回退

尚未确定协议时先保留方案记录，不覆盖现有服务或混装另一套配置。
