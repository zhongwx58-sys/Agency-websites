# 开通 登录与基础准备

说明控制台、SSH、系统更新、登录凭据和必要端口。

## 控制台与 SSH 各自做什么

控制台用于查看实例状态、地址、网络规则与恢复入口；SSH 用来登录操作系统。首次连接前从控制台核对地址与主机指纹，避免只因看到连接提示就盲目信任。使用自己的登录账户和密钥，不在共享文档中保存私钥正文。

## 在新实例上建立基础记录

以下是 Ubuntu 服务器的准备顺序。已有业务的主机不能照搬新实例操作；系统更新或防火墙变化前应确认服务影响。

1. 记录实例名称、公网地址、系统版本和架构。
2. 用 SSH 登录，核对主机名、系统时间和磁盘空间。
3. 按 Ubuntu 文档管理更新与账户，保留可再次登录的会话。
4. 分别检查云端网络规则和系统防火墙，只开放方案需要的端口。

## 验证登录后再收紧入口

改变 SSH 登录方式之前，先在第二个终端验证新账户或密钥能登录，并确认控制台救援可用。云安全规则和系统防火墙是两层限制；只改其中一层不一定能使服务可达。把端口用途写清楚，例如管理入口与代理服务入口，不把服务监听范围混为一谈。

## 常见误区

不要在尚未验证新登录方式时关闭当前唯一入口。

## 恢复与回退

保留现有会话，使用控制台恢复误改的登录或防火墙配置，再重新验证。
