# 住宅 ISP 与数据中心

分清 IP 属性、产品称呼和检测数据库标签。

## 先把三个描述分开

产品名称是提供方对服务的描述；ASN 和网络归属来自网络分配信息；检测网站的住宅、托管或代理标签则是数据库分类。它们可以互相参考，但不是同一种证据。一个页面标为住宅，并不能直接证明它就是某个家庭中正在使用的线路。

## 沿着实际请求核对

先确定检测页面是否走了你选择的出口，再读取地区、ASN 和组织信息。手动输入一个地址得到的归属资料，不证明当前浏览器从那个地址访问。地区库也可能更新滞后；不同来源出现差异时，把原始地址与查询日期一起保留。

1. 查看客户端中检测站请求的实际节点。
2. 记录当前访问来源的 IP 与地址族。
3. 查询同一地址的 ASN、组织和类型标签。
4. 将产品说明和查询结果分别填写，不互相覆盖。

## 标签之后还要看能力

真正影响使用的是可达性、认证、带宽、延迟、协议支持和目标网站的响应。标签无法保证账号稳定，也不能保证某个平台永久接受该 IP。首次接入应先完成第 4.5 课的能力检查，再记录它在自己具体用途中的表现。

## 常见误区

不能用单个“住宅”标签或风险分数代替真实目标测试。

## 恢复与回退

发现标签矛盾时保留原始数据，重新核对请求路径，再比较多个来源。
