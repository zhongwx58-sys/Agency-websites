# Windows 完整图文

分别制作 Clash Verge Rev、v2rayN 的安装、使用、验证与恢复。

## 版本与素材范围

本课保留 V2 大纲的完整图文课题名称，第一版先提供两条独立步骤路线。真实 Windows 安装与操作截图尚待补充，以下属于官方资料整理；不同版本菜单可能变化。先确认系统架构，安装材料只从项目官方发布入口获取。

## 路线 A：Clash Verge Rev

它的导入与配置路线按 Mihomo 能力核对。首次验证先使用浏览器和系统代理，TUN 作为后续独立步骤。

1. 下载匹配架构的安装包，安装后记录客户端与内核版本。
2. 在订阅页面导入适配配置，并选中它。
3. 在代理页面选节点，确认规则模式及目标策略。
4. 开启系统代理，访问目标并查看连接与日志。

## 路线 B：v2rayN

按项目 Wiki 中当前版本的说明导入分享链接或订阅，在服务器列表选中要使用的节点；核对该协议对应的内核。设置系统代理与路由时，记录选项原值。不要直接导入 Mihomo 的完整 YAML 当作 v2rayN 节点参数。

1. 新增订阅分组并更新，或导入单节点链接。
2. 选定节点，检查内核启动日志没有参数错误。
3. 启用适合测试的系统代理方式，发起实际请求。

## 共同的验证与恢复

两条路线都要分别检查连接、出口与目标功能。测试期间仅保留一个客户端接管网络。结束时先关闭它启用的系统代理或 TUN，再退出程序；最后核对 Windows 代理设置与原状态一致。截图应包含操作入口与结果，但遮挡订阅和账号。

## 常见误区

两个客户端可能争用系统代理或虚拟网卡；不要把冲突表现直接归因于节点。

## 恢复与回退

停止本次客户端的接管，恢复原系统代理设置并切回旧配置。
