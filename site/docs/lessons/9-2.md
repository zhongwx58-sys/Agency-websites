# 当前出口与指定 IP 查询

区分检测本次访问来源和手动查询某个地址的资料。

## 识别页面正在查询谁

打开“当前 IP”页面时，网站通常展示它看到的这次访问来源；在搜索框填入一个 IP 时，网站展示的是该地址的资料。后者不会证明你的流量正在经过它。截图时保留页面名称、查询条件和时间，避免把手动输入的节点 IP 当作实际出口检测结果。

## 把网页结果和连接对应起来

先记录预期出口，再打开当前 IP 页面，回到客户端确认这个检测域名走了哪条规则。如果它被设置为直连，显示本地网络公网地址并不说明其他目标也直连；如果浏览器使用独立代理扩展，结果还可能与系统设置不同。需要从同一次请求的证据解释结果。

1. 清楚区分当前 IP 检测页与指定 IP 查询页。
2. 记录返回地址是 IPv4 还是 IPv6。
3. 保存检测域名的命中规则与策略链。

## 地址不同先查条件

代理服务入口地址和对外出口地址可能不同，轮换服务也可能在新会话改变出口。不要要求网页返回值机械地等于订单中填写的服务器地址。先确认服务是否声明固定出口、是否存在 IPv6，以及检测请求有没有走预定路径，再决定这是正常设计还是配置偏差。

## 常见误区

用手动查询某个住宅 IP 的页面证明当前请求具有住宅出口。

## 恢复与回退

关闭指定地址查询，重新打开当前出口检测页并获取新的对应连接。
