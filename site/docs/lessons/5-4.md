# Android 完整图文

分别整理 FlClash、v2rayNG、sing-box 的导入、权限与使用。

## 准备设备与素材记录

本课为官方资料整理，未在 Android 实机复现；原大纲中的完整图文将在设备步骤核对后补齐。先记录 Android 版本、芯片架构、客户端来源与版本。三款客户端各走自己的导入路线，不共用一份完整配置。

## FlClash 与 v2rayNG

FlClash 按其项目说明导入适配的 ClashMeta 配置，选择策略后启动连接。v2rayNG 从节点分享链接或相应订阅导入，选择节点后启动服务。二者都应在发起连接时阅读系统 VPN 权限提示，授权后查看客户端状态与日志。

1. 从对应项目发布入口获取匹配安装包。
2. 导入后确认列表中出现预期资源。
3. 选择节点并启动，只让当前测试客户端承担接管。

## sing-box 官方客户端

使用 sing-box for Android 的配置管理流程，导入适配当前内核版本的配置，核对日志后启动。它的 JSON 结构与 Xray 不相同，订阅来源需要明确支持该客户端。涉及分应用、后台运行等设置时，按客户端功能页和系统实际界面核对。

## 分别检查前台与后台

先在前台完成连接、出口和目标访问，再切换应用、锁屏和切换网络做需要的使用检查。后台失败要记录电池策略、服务状态和日志，不直接判定是节点问题。停止测试时在客户端断开，再检查系统 VPN 状态及原网络是否恢复。

## 常见误区

系统节电行为与不同厂商界面有差异，不能把某一设备的设置写成通用路径。

## 恢复与回退

停止当前 VPN，恢复本次改变的应用或后台设置，再检查直连访问。
