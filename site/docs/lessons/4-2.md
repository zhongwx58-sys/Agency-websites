# 固定 轮换 共享与独享

解释地址变化、会话保持、并发和使用限制。

## 用两条轴描述资源

固定或轮换描述地址如何随时间与请求变化；共享或独享描述使用资源的分配方式。四个词不能合并成一条从低到高的等级。固定出口仍可能因续期、故障或资源调整发生变化，独享的具体范围也要看服务说明。

## 把会话条件写清楚

有些轮换服务允许通过用户名参数或会话标识，在一段时间内尽量使用同一出口。字段格式和保持条件属于提供方协议，本教程不编造通用参数。先确认什么时候会切换，再用相同条件重复请求观察。

1. 记录轮换触发条件：每次请求、时间间隔或手动切换。
2. 核对会话保持时间、断线后的行为与续期变化。
3. 核对最大并发、设备限制和允许的协议。
4. 在同一测试条件下记录连续几次出口，注明时间。

## 根据任务判断合适与否

需要连续登录会话的任务，通常更关心地址是否保持；短时读取任务可能更关心可达性和响应速度。先记录任务需求，再解释观察结果，不根据名称下结论。一次地址未变化只能说明这个测试窗口，不能证明长期固定。

## 常见误区

入口域名不变，不代表它背后的最终出口地址不变。

## 恢复与回退

出现意外轮换时停止依赖固定出口的操作，核对会话参数与当前服务状态。
