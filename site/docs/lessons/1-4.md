# 第一次导入与启用

提供最短操作路线，完整平台差异链接到客户端专篇。

## 本课采用一个明确入口

以下以 Clash Verge Rev 的订阅导入思路说明最短过程，依据官方入门文档整理。界面文字可能随版本变化；其他客户端请进入第 5 模块对应课程。本版尚无这台设备的实拍步骤，不能把文字流程理解为已在你的网络验证。

## 导入、选中、再接管

先让客户端正确读取配置，再开始改变请求路径。导入成功只证明材料能被客户端处理，不能证明远程节点可用。

1. 在订阅或配置页面粘贴适配的链接，导入并等待下载结束。
2. 选中这份配置，在代理页面选择一个节点，记下名称。
3. 使用规则模式进行首次浏览器测试，确认测试域名会走预期策略。
4. 先开启系统代理；只有需要接管不遵循系统代理的应用时，再按专篇检查 TUN。

## 马上检查一条请求

打开连接页面，再访问预先选好的目标。按域名找到新连接，记录它选中的策略和节点。如果列表没有这条请求，先检查应用是否使用系统代理；如果出现连接但访问失败，再看错误类别。不要同时切换节点、DNS 和接管模式，否则无法判断哪次修改产生了影响。

## 常见误区

延迟显示数字不代表目标网站已能打开；也不要同时启用多个客户端接管网络。

## 恢复与回退

关闭刚启用的系统代理或 TUN，切回导入前的配置，再检查原有网页。
