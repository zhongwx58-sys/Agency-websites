# 整理订单与认证参数

核对地址、端口、HTTP 或 SOCKS、账号密码及白名单方式。

## 先保存原始字段名

从自己的服务控制台整理连接参数：入口地址、端口、协议、用户名、密码、授权方式和可能的会话字段。HTTP 与 SOCKS5 不是根据端口自动决定；端口相同也可能使用不同协议。不要自行把产品名称写进协议字段。

## 区分账号认证与来源白名单

账号密码验证凭据；来源白名单限制谁可以连接这个代理入口。若通过前置连接，服务看到的来源可能是前置的出口，而不是你的家庭公网地址。应根据实际链路和提供方说明核对，不随意扩大白名单范围。

1. 逐项抄录字段并核对大小写和特殊字符。
2. 确认使用用户名密码、白名单，还是两者同时要求。
3. 记录凭据有效期和更换方式。
4. 在客户端新增节点后检查保存值，公开截图全部脱敏。

## 建立可公开与不可公开两份记录

私人记录保存真实连接材料；教程或排错记录仅保留字段名、协议、错误类别和必要的非敏感条件。某些用户名本身包含地区或会话信息，不能只遮挡密码。导入失败先检查空格、转义与字段对应，不要用反复重置密码代替定位。

## 常见误区

账号中的地区或会话后缀可能是协议的一部分，不能任意删改。

## 恢复与回退

回到控制台原始参数逐字段核对；凭据暴露时按提供方流程更换，并同步更新客户端。
