# 客户端接入与出口验证

导入节点，分别核对服务可达、代理链路、出口与目标访问。

## 逐字段对照服务端

从已部署方案提取客户端需要的地址、端口、协议、认证、传输与安全参数。服务端监听地址不一定是客户端连接地址，例如服务器监听所有接口时，客户端仍要使用实际公网地址或域名。不要把服务端完整配置直接当作客户端配置导入。

## 单节点验证优先

先使用一个客户端直接连接自建节点，暂不加入前置链式。这样失败时能够把问题限制在本地接入、服务器入口和目标访问之间。

1. 按第 5 模块的客户端路线新增节点，核对所有参数。
2. 确认服务器网络规则允许该服务端口。
3. 启动客户端并访问测试目标，同时查看服务端对应时间的日志。
4. 记录目标请求的节点、出口地址和网页访问结果。

## 把错误对应到层次

超时可能发生在网络或服务入口，认证错误说明应先核对凭据，TLS 错误需要检查安全与传输参数。错误词语是定位线索，不能单独证明根因。若出口符合预期但网站不可用，应继续分析目标响应，不能直接归为服务器安装失败。保留本次的最小可用配置。

## 常见误区

端口测试成功只说明某种连接可建立，不能替代代理协议与目标访问验证。

## 恢复与回退

切回原节点；服务端保留可用配置，在副本上修改单个问题字段后重新检查。
