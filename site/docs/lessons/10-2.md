# Mihomo YAML 主线

学习缩进、列表、代理集合、策略组与规则组织。

## 先辨认映射与列表

YAML 使用缩进表达层级，键后面的冒号连接字段与值，短横线常用于列表项。编辑时使用空格并保持同级字段一致，不要混入制表符。节点名称、组名称与规则引用必须准确对应；文件看起来整齐，并不代表引用关系正确，仍需要内核检查。

## 读一个不含真实节点的片段

下面只演示规则与组的关系，示例直连组不会提供代理能力。实际配置还需要你的入站、DNS、节点或代理集合等内容。proxy-providers 用于引入代理资源，proxy-groups 用于组织选择，rules 用于分配请求；不要把规则集文件塞进代理集合。

```yaml
# 结构教学片段，非完整代理配置
proxy-groups:
  - name: 本地直连
    type: select
    proxies:
      - DIRECT
rules:
  - DOMAIN,example.com,本地直连
```

## 分开检查语法和功能

先检查缩进、缺失字段和未知引用，再确认客户端加载的是这份配置。之后发起请求检查命中与出口。密码中包含特殊字符时应按 YAML 语法正确引用，不要为方便而删掉字符。出错行附近往往只是解析器发现问题的位置，真正错误也可能在前面一行的缩进或引号。
