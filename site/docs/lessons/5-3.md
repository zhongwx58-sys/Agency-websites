# macOS 完整图文

分别整理 Clash Verge Rev、Surge 的权限、接入与平台差异。

## 先标明本课范围

本课为官方资料整理，尚未在 macOS 实机复现，也没有可冒充实拍的步骤截图。保留原大纲课题名称以便后续补充。安装前确认 Apple 芯片或 Intel 架构、系统兼容范围，并保存原网络代理设置。

## 路线 A：Clash Verge Rev

从官方入口下载匹配架构的安装包，启动后导入适配订阅、选择配置和节点。先开启系统代理测试浏览器；需要 TUN 时再依当前文档检查服务权限。若系统阻止应用运行，先确认来源和系统说明，不以关闭所有安全机制作为常规步骤。

1. 记录版本与安装来源。
2. 导入后检查节点、策略与规则。
3. 发起请求并查看连接结果。

## 路线 B：Surge

Surge 使用自己的配置文件组织代理策略、策略组与规则。按官方 Quick Start 准备配置，核对策略选择后开启相应流量接管；系统代理与增强模式各自影响不同入口。不要直接粘贴 Mihomo 的 YAML。首次验证只使用必要功能，不需要为普通代理接入配置 HTTPS 解密。

## 独立记录权限与恢复

把系统授权、服务状态和实际接管模式写进操作记录。结束时关闭本次开启的模式，核对网络服务里的代理设置以及日常应用访问。之后补图时需记录系统和客户端版本、截图日期与对应步骤，不能用其他版本图片声称当前实测。

## 常见误区

macOS 与 Windows 同名客户端也可能有不同权限流程，不能照搬系统操作。

## 恢复与回退

关闭本次接管模式，恢复原网络服务代理选项，保留原配置。
