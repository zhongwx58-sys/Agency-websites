# 机场 节点与订阅的关系

解释服务提供方、节点资源、分享链接和订阅配置的区别。

## 分清四个对象

服务提供方管理资源与账户；节点描述一条连接入口；分享链接携带某个节点的参数；订阅是更新这些材料的渠道。同一个订阅可以提供多个节点，不同客户端格式还可能携带不同的规则和策略。订阅本身不是网络协议。

## 看看导入后多了什么

导入一份已知来源的订阅后，观察新增的是节点组，还是一份带 DNS、规则和策略组的完整配置。前者通常需要现有配置引用；后者可能接管原来的分流行为。两者虽然都可以叫“订阅”，更新的影响范围并不相同。

1. 记录订阅来源和适配格式，不公开完整地址。
2. 数一下导入前后的节点，观察是否新增策略组。
3. 查看规则和 DNS 是否发生变化，记录原来的自定义内容。

## 理解更新与服务状态

更新是重新拉取提供方的内容，可能增加、删除或改名节点。更新成功不表示每个节点都可连接，更新失败也不一定立即使缓存中的节点失效。把订阅下载状态、节点可达性和账户有效期分别检查，才能知道问题发生在哪一层。

## 常见误区

不要把订阅获取成功当作全部节点的运行保证。

## 恢复与回退

更新前保留可用配置；失败后先恢复缓存或旧版本，再检查下载错误。
