# 共同确认资源条目

只在你确认使用经历后写个人评价，保留时间与当前状态。

## 先确定条目的证据级别

每个资源条目先选择“资料整理”“用户确认用过”或“本教程已实操复现”。这三个状态不能相互替代。过去用过也不等于今天仍然可用；完成某一客户端接入，并不代表该服务的所有地区和协议都测过。

## 填写一份可核对记录

资源页的目的，是帮助读者判断适用条件，而不是给出未经解释的好坏排名。现在还没有共同确认的个人使用名单，因此本课提供记录方法，不生成推荐商家。

1. 填写名称、官方入口、资源类别和记录日期。
2. 注明是谁在何时、何种设备和网络中使用过。
3. 用具体任务描述优点、缺点和失败情况。
4. 保留脱敏截图或日志的位置，关联相应课程。

## 更新时保留历史边界

新一轮核对可补充当前可用状态，但不应抹去旧测试的条件。价格与套餐变化另记日期，失效链接不要继续作为当前入口。发布素材前检查账号、订阅、二维码、推广参数和截图中的广告，只留下读者完成操作真正需要的信息。没有证据的字段保持待确认。

## 常见误区

不能根据公开介绍替用户编写“长期使用”“强烈推荐”等经历。

## 恢复与回退

发现条目失实时先撤下具体结论，保留来源和修订时间，再补做核对。
