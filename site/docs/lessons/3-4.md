# 安装 配置与服务检查

记录安装步骤、协议参数、监听状态和服务日志。

## 先知道每个文件的职责

安装程序文件后，仍需要一份与选定协议相符的配置，以及明确的启动方式。下面给出 Xray 的只读诊断命令示例；配置路径仅是常见安装位置，必须替换成自己实际使用的路径。它不是一份可以直接提供代理的完整服务端配置。

## 先检查，再启动服务

将协议参数整理进独立配置文件，先进行配置检查。只有检查通过，才按安装方案启动对应服务，并检查实际监听和日志。不要为了绕过报错而随意删除认证或传输字段。

1. 确认命令显示预期的内核版本。
2. 配置检查通过后，核对服务读取的文件是否正是这一份。
3. 在监听列表中找到配置端口与对应进程。

```bash
xray version
xray run -test -config /usr/local/etc/xray/config.json
systemctl status xray --no-pager
journalctl -u xray -n 50 --no-pager
ss -lntup
```

## 区分本机正常与外部可达

服务处于运行状态只说明进程还在，监听成功只说明本机接受指定入口。云端规则、防火墙、认证和协议仍可能导致外部访问失败。日志包含凭据或目标信息时先脱敏，再与客户端失败时间对应。下一课从客户端发起一条真实请求验证完整路径。

## 常见误区

systemd 服务名和安装路径随方案变化，不能机械复制示例路径。

## 恢复与回退

配置检查失败时不要替换正在使用的配置；恢复上一个可用文件，再检查差异。
