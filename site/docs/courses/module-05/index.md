# 全平台客户端专篇

在自己的系统中找到完整且独立的操作路线。

## 本模块目标

按所选客户端完成接入、查看日志和连接，并恢复原状态。

## 课程顺序

1. [客户端 内核与配置适配](/lessons/5-1.html)：说明订阅格式、内核语法和界面操作的关系。
2. [Windows 完整图文](/lessons/5-2.html)：分别制作 Clash Verge Rev、v2rayN 的安装、使用、验证与恢复。
3. [macOS 完整图文](/lessons/5-3.html)：分别整理 Clash Verge Rev、Surge 的权限、接入与平台差异。
4. [Android 完整图文](/lessons/5-4.html)：分别整理 FlClash、v2rayNG、sing-box 的导入、权限与使用。
5. [iOS 完整图文](/lessons/5-5.html)：分别制作 Shadowrocket、Surge、sing-box 的导入与操作。
6. [跨设备迁移与复核](/lessons/5-6.html)：核对配置兼容、参数和规则，迁移后重新验证路径。
