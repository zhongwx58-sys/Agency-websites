# 机场与订阅服务

理解订阅服务，学会接入、维护并记录真实体验。

## 本模块目标

解释订阅内容，完成导入与更新，并给出有条件的使用反馈。

## 课程顺序

1. [机场 节点与订阅的关系](/lessons/2-1.html)：解释服务提供方、节点资源、分享链接和订阅配置的区别。
2. [选型与费用怎么看](/lessons/2-2.html)：理解地区、流量、速率、设备限制、有效期和计费周期。
3. [获取并导入订阅](/lessons/2-3.html)：围绕后续共同确认的服务制作控制台到客户端的操作图文。
4. [日常使用与订阅更新](/lessons/2-4.html)：说明节点选择、更新、流量查看与自定义配置保留。
5. [怎样记录好用与不足](/lessons/2-5.html)：按具体网络、时段、用途记录延迟、速度、稳定性和问题。
6. [共同确认资源条目](/lessons/2-6.html)：只在你确认使用经历后写个人评价，保留时间与当前状态。
