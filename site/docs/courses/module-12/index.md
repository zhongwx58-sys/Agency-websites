# 故障诊断与复盘

按证据缩小问题范围，并能恢复到已知状态。

## 本模块目标

给出可复查的定位过程和恢复结果，保留仍待核实的部分。

## 课程顺序

1. [导入与配置解析失败](/lessons/12-1.html)：检查资源响应、格式、语法和客户端兼容性。
2. [连接超时与认证失败](/lessons/12-2.html)：检查可达性、地址端口、认证和服务状态。
3. [有延迟但打不开网页](/lessons/12-3.html)：依次区分 DNS、代理连接、TLS、网站响应与应用请求。
4. [链式或出口不符合预期](/lessons/12-4.html)：检查节点选择、实际连接、前置与落地顺序。
5. [规则 TUN 或更新后异常](/lessons/12-5.html)：检查优先级、权限、接管模式和配置变化。
6. [组织排错材料](/lessons/12-6.html)：记录版本、脱敏参数、日志、复现步骤、处理与恢复结果。
