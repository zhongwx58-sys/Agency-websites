# VPS 自建完整路线

从服务器准备走到客户端使用，并能持续维护。

## 本模块目标

用记录完整的方案完成部署与接入，知道如何更新和恢复。

## 课程顺序

1. [服务器选型与费用](/lessons/3-1.html)：比较地区、线路、带宽、流量、系统、IP 与续费成本。
2. [开通 登录与基础准备](/lessons/3-2.html)：说明控制台、SSH、系统更新、登录凭据和必要端口。
3. [选择可复现的部署方案](/lessons/3-3.html)：先固定一条 Xray 或 sing-box 教学主线，核对官方安装来源。
4. [安装 配置与服务检查](/lessons/3-4.html)：记录安装步骤、协议参数、监听状态和服务日志。
5. [客户端接入与出口验证](/lessons/3-5.html)：导入节点，分别核对服务可达、代理链路、出口与目标访问。
6. [更新 备份 迁移与停用](/lessons/3-6.html)：管理版本、配置、费用与资源释放，给出恢复和迁移步骤。
