# 配置文件与持续维护

让配置可阅读、可更新、可恢复。

## 本模块目标

能修改本路线相关配置，在更新或修改失败后恢复并复核。

## 课程顺序

1. [阅读配置的整体结构](/lessons/10-1.html)：按入站、DNS、节点、策略、规则定位修改位置。
2. [Mihomo YAML 主线](/lessons/10-2.html)：学习缩进、列表、代理集合、策略组与规则组织。
3. [Xray 与 sing-box 分支](/lessons/10-3.html)：按各自内核解释结构与示例，避免直接混用配置。
4. [Surge 与 Shadowrocket 分支](/lessons/10-4.html)：介绍对应格式、导入方式与支持范围。
5. [订阅与节点持续更新](/lessons/10-5.html)：保存自定义修改，更新后检查规则、链式和资源内容。
6. [版本 备份与恢复](/lessons/10-6.html)：记录系统与内核版本，必要时回退并再次验证。
