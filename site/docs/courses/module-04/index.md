# 住宅代理与 ISP 出口

理解出口属性和接入条件，完成可核对的使用。

## 本模块目标

知道住宅标签能说明什么，并按实际参数完成接入与验证。

## 课程顺序

1. [住宅 ISP 与数据中心](/lessons/4-1.html)：分清 IP 属性、产品称呼和检测数据库标签。
2. [固定 轮换 共享与独享](/lessons/4-2.html)：解释地址变化、会话保持、并发和使用限制。
3. [整理订单与认证参数](/lessons/4-3.html)：核对地址、端口、HTTP 或 SOCKS、账号密码及白名单方式。
4. [直接接入与前置接入](/lessons/4-4.html)：根据可达性选择接入方式；需要前置时转到链式代理模块。
5. [出口与能力验证](/lessons/4-5.html)：核对出口、IPv4 或 IPv6、TCP 或 UDP 和目标网站访问。
6. [选型体验与维护记录](/lessons/4-6.html)：记录适用场景、不足、费用、续期、切换与恢复方式。
