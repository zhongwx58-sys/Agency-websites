# 分流规则编写与调试

用明确条件安排请求路径，并用连接证据核对。

## 本模块目标

能添加、解释和调试一条规则，并核对对应请求的实际路径。

## 课程顺序

1. [规则 策略组与节点](/lessons/8-1.html)：分清请求匹配、路径选择和建立连接的职责。
2. [域名规则](/lessons/8-2.html)：学习精确、后缀等匹配，辨别同一网站相关域名。
3. [IP 进程与应用规则](/lessons/8-3.html)：讲解 CIDR、进程或应用规则及各平台支持差异。
4. [规则顺序与兜底](/lessons/8-4.html)：说明优先级、冲突和未命中时使用的路径。
5. [规则集与自定义修改](/lessons/8-5.html)：核对格式、更新方式和自定义规则放置位置。
6. [验证与教学演示](/lessons/8-6.html)：查看命中规则与链路，用演示数据说明顺序变化的影响。
