# IP 检测工具与结果解读

知道每类检测回答什么，并完成交叉验证。

## 本模块目标

能解释测试结果及局限，不把单站结论扩展到所有应用与未来状态。

## 课程顺序

1. [常用检测网站与用途](/lessons/9-1.html)：按出口、地区与 ASN、DNS、WebRTC 和 IPv6 介绍工具。
2. [当前出口与指定 IP 查询](/lessons/9-2.html)：区分检测本次访问来源和手动查询某个地址的资料。
3. [地区 ASN 与出口标签](/lessons/9-3.html)：解释数据库差异，不把住宅标签或风险分数当成保证。
4. [DNS WebRTC 与 IPv6](/lessons/9-4.html)：逐图运行相关检测，结合代理设置解释可观察信息。
5. [不同网站结果不一致](/lessons/9-5.html)：先对照规则、连接、IPv4 与 IPv6，再分析数据库差异。
6. [形成可复查的检测记录](/lessons/9-6.html)：同时保存检测条件、截图、连接日志、时间和实际访问结果。
