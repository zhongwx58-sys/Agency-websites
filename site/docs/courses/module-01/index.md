# 入门基础与首次连接

选择路线并尽早完成一次可核对的连接。

## 本模块目标

完成一次连接和恢复，并说明该请求经过的路径。

## 课程顺序

1. [按现有资源选路线](/lessons/1-1.html)：区分已有订阅、希望自建、已有住宅代理和暂未准备资源。
2. [看懂设备到网站的路径](/lessons/1-2.html)：认识客户端、内核、节点、入口、出口、域名、端口与 DNS。
3. [准备导入材料](/lessons/1-3.html)：整理订阅链接、节点参数或配置文件，记录系统和客户端版本。
4. [第一次导入与启用](/lessons/1-4.html)：提供最短操作路线，完整平台差异链接到客户端专篇。
5. [核对首次连接结果](/lessons/1-5.html)：看连接记录、实际链路和出口，再检查目标网站访问。
6. [关闭与恢复](/lessons/1-6.html)：保存旧配置，关闭代理并核对原网络状态。
