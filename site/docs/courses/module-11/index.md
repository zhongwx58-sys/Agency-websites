# 综合案例与个人实践

把真实使用经历整理成可跟随的图文案例。

## 本模块目标

每个案例都有可核对的依据，读者可按步骤操作并判断结果。

## 课程顺序

1. [机场日常接入与分流](/lessons/11-1.html)：从订阅到规则命中，核对多个实际请求的路径。
2. [从 VPS 自建到客户端](/lessons/11-2.html)：将开通、部署、连接、维护整理成连续案例。
3. [机场接住宅出口](/lessons/11-3.html)：完整记录参数、链式、分流与最终出口检查。
4. [指定网站使用特定出口](/lessons/11-4.html)：核对相关域名和客户端连接，说明覆盖范围。
5. [你实际用过的资源案例](/lessons/11-5.html)：共同确认使用场景、好用的理由、不足与现有截图。
6. [整理个人配置与检测说明](/lessons/11-6.html)：给出路径图、脱敏配置、实测条件和恢复方法。
