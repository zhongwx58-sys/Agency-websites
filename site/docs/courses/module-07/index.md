# 链式代理完整实操

把机场、自建节点和住宅出口接回同一张路径图。

## 本模块目标

测试请求走预定链路，出口符合预期，失败时能分段定位。

## 课程顺序

1. [使用场景与代价](/lessons/7-1.html)：解释多一跳的依赖、延迟和维护工作。
2. [前置与落地顺序](/lessons/7-2.html)：统一使用设备 → 前置代理 → 落地出口 → 目标网站。
3. [机场节点接住宅代理](/lessons/7-3.html)：逐图填写出口与认证参数，并选择正确的最终出口。
4. [机场节点接自建 VPS](/lessons/7-4.html)：衔接已部署节点，核对协议与传输能力。
5. [按内核配置并保存](/lessons/7-5.html)：分别维护 Mihomo、Xray、sing-box 和苹果客户端的操作。
6. [逐段验证与排错](/lessons/7-6.html)：检查前置、落地、组合路径、最终出口、目标访问和更新结果。
